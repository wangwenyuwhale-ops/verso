A sleek product landing page for an AI-powered creative and knowledge management platform. The project presents an experience-focused design system for writing assistance, knowledge graph building, semantic search, and collaborative ideation.

这是一个面向 AI 创作与知识管理平台的高颜值产品页，重点展示 AI 写作、知识图谱、语义搜索、创意协作等核心能力，适合用于作品展示、产品演示和 GitHub 作品页发布。

## ✨ Project Overview / 项目概览

VERSO is a concept product page designed to showcase how an AI-native workspace can help users capture ideas, organize knowledge, generate content, and connect scattered thoughts into a meaningful knowledge network.

VERSO 是一个概念型 AI 产品页面，展示一个 AI 原生工作台如何帮助用户：

- 捕捉灵感与创意
- 生成结构化内容
- 构建知识图谱
- 进行语义检索
- 协作共享与版本回溯

This project is built as a single-page static showcase and is suitable for portfolio presentation, product concept demos, and GitHub showcase pages.

本项目采用静态单页实现，适合用于作品集展示、产品概念演示以及 GitHub 项目展示。

## 🧩 Core Features / 核心功能

### AI Writing Assistant
- Generate structured content from brief prompts
- Support tone and style adjustments
- Assist with first drafts and creative expansion

### Knowledge Graph
- Connect related notes and documents
- Visualize concept relationships
- Reveal hidden links between ideas

### Semantic Retrieval
- Find information based on meaning rather than exact keywords
- Search across notes and content blocks quickly

### Collaboration Workspace
- Shared knowledge space for teams
- Inline comments and suggestions
- Shared mental model and topic graph

### Version History & Knowledge Curation
- Track iterative writing and updates
- Restore previous versions
- Convert ideas into reusable knowledge assets

## 🛠 Tech Stack / 技术栈

- HTML5

## 🚀 Quick Start / 快速开始

### 1. Clone the project

```bash
git clone https://github.com/<your-username>/verso.git
cd verso
```

### 2. Open the page locally

You can either:

- Open `index.html` directly in the browser, or
- Run a local static server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
